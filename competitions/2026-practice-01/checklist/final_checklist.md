# Final Checklist

## 论文

- [ ] 题目、队伍编号和日期已确认。
- [ ] 摘要不含未验证结果。
- [ ] 问题重述没有照抄题面。
- [ ] 假设合理，并在局限性中讨论。
- [ ] 符号说明与正文一致。
- [ ] 所有公式均为 LaTeX 格式。
- [ ] 结论只来自真实数据、代码输出和验证结果。

## 数据与代码

- [ ] 原始数据保存在 `data/raw/`，未被覆盖或手工改写。
- [ ] 清洗后数据由 `code/preprocessing.py` 生成。
- [ ] 模型结论可追溯到 `code/` 中的脚本或 Notebook。
- [ ] 实验记录写入 `logs/experiment_log.md`。
- [ ] 关键建模决策写入 `logs/decision_log.md`。

## 图表

- [ ] 论文引用的每个图像文件都真实存在。
- [ ] 论文引用的每个表格文件都真实存在。
- [ ] 图像由 Python 或 draw.io 源文件导出。
- [ ] 表格结果由代码生成或有明确来源。
- [ ] 图表标题、编号和正文说明一致。

## 参考文献

- [ ] `paper/references.bib` 来自 Zotero 或可信来源。
- [ ] 每条参考文献都实际阅读或使用。
- [ ] 正文引用与参考文献条目一致。
- [ ] 没有编造文献、失效来源或未引用条目。

## 编译与提交

- [ ] 使用 XeLaTeX 编译通过。
- [ ] LaTeX 日志没有 `LaTeX Error` 或 `Undefined control sequence`。
- [ ] 最终 PDF 在 `output/` 中生成。
- [ ] `.gitignore` 未误忽略必要源文件。
- [ ] Git 状态已检查，提交内容范围清楚。
