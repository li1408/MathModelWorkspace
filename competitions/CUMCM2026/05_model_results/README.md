# 05_model_results

用于保存模型运行后的结果、评价指标和日志。

## 子目录

- `tables/`：模型输出表格，可供论文或支撑材料引用。
- `metrics/`：误差指标、评分指标、模型对比指标。
- `logs/`：模型运行日志、参数记录和异常记录。
- `runs/<run_id>/`：显式 profile 的隔离结果；包含运行清单、配置快照、输入校验值、环境、阶段报告及各实验子目录。

## 规则

- 每个关键结果必须能追溯到对应代码、输入数据和运行配置。
- 不把尚未验证的临时结果写入论文。
- 重要结果需要记录生成时间、脚本名称和参数。
- `runs/` 可能包含大文件和冷启动副本，默认由 Git 忽略；需要冻结时只复制经过复核的必要材料。
- baseline、alternatives、convergence 必须写入各自子目录，且论文证据必须引用明确的 `source_run_id`。
